# Consagração Total

PWA para a preparação de 33 dias da Consagração Total a Jesus por Maria, segundo São Luís Maria Grignion de Montfort.

- `npm run dev` — desenvolvimento
- `npm test` — testes (calendário, roteiro, textos, progresso)
- `npm run build` — gera `dist/` (estático; o Vercel detecta Vite sozinho)

Os textos em `src/data/texts/` são transcrições literais das fontes citadas em `src/data/texts.ts` (`SOURCES`).
As ferramentas e correções de transcrição ficam em `tools/transcription/`.
